Cài đặt API Key

Kết nối nhà cung cấp AI của bạn để chuẩn bị sử dụng các tính năng học tập.

Kết nối AI

Trạng thái đã lưu không đồng nghĩa với kết nối hợp lệ. Dùng nút kiểm tra bên dưới để xác nhận.

Để trống khi kiểm tra key đã lưu của cùng nhà cung cấp. Nhập key mới khi lưu hoặc đổi nhà cung cấp.

Kiểm tra sẽ gửi một yêu cầu AI ngắn và có thể sử dụng hạn mức hoặc phát sinh phí theo tài khoản của bạn. Key đang nhập chỉ được lưu khi bạn bấm Lưu vào phiên.

Lấy API key

  1. Mở trang nhà cung cấp và đăng nhập.
  2. Tạo API key cho tài khoản của bạn.
  3. Dán key, chọn đúng nhà cung cấp và kiểm tra kết nối.
Google AI Studio ↗ Groq Console ↗ OpenAI Platform ↗

Riêng tư trong phiên

Key chỉ lưu trong phiên trên máy chủ, không ghi vào cơ sở dữ liệu. Khi đăng xuất hoặc phiên hết hạn, bạn cần nhập lại.

Không chia sẻ API key hoặc chụp ảnh key khi đang hiển thị.
