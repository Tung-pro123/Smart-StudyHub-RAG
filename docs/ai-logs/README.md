## 🎯 1. TẠI SAO BẮT BUỘC MỖI BẠN PHẢI TỰ VIẾT AI LOG?
Trong môn học này, Giảng viên đánh giá rất cao kỹ năng **áp dụng công cụ AI hỗ trợ lập trình (AI-Assisted Coding / Pair Programming)** trong môi trường IDE (Cursor, GitHub Copilot, Gemini, ChatGPT).  
Mỗi thành viên cần tự lưu lại tiến trình thực tế của chính mình để chứng minh:
1. Bạn không copy-paste bừa bãi, mà có tư duy **Prompt Engineering** rõ ràng khi yêu cầu AI viết code.
2. Bạn trực tiếp dùng AI để thiết kế giao diện (Thymeleaf/Tailwind), viết Backend (Spring Boot), và debug gỡ lỗi.
3. Khi vấn đáp, giảng viên sẽ mở file AI log này ra để hỏi bạn: *"Tại sao bạn lại prompt câu này? AI trả về đoạn code này bạn đã sửa lại những gì?"*.

2. **Tạo file nhật ký của riêng bạn**:
   - Trong thư mục `docs/ai-logs/`, copy file [template.md](file:///d:/Ki5_Fall_2026/HSF302/Assignment/Assignment/docs/ai-logs/template.md) và đổi tên thành tên của bạn:

     - Bạn **Trường**: Tạo file `ai-log-truong.md`

3. **Ghi lại 3 giai đoạn chính trong quá trình code**:

   - Bạn Trường (Master QA) sẽ dùng các ảnh này để đưa vào cuốn **User Guide Word/PDF** và **Slide PowerPoint** báo cáo trước lớp!
